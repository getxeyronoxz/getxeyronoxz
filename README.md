### 📂 Systems Architecture & Blueprints

```text
[SYS-01] HASU (蓮) 2.0 // SYMBIOTIC 3D DESKTOP AGENT
```
* **Mission:** Persistent, living desktop presence designed for natural voice interaction and safe PC automation.
* **Dual-Runtime Engine:** Native **Rust Core** (`hasu-core`) handling transparent Win32 DirectComposition windowing and 60Hz surface physics, communicating over local IPC with a self-contained **.NET 10** automation sidecar (`SendInput`, Direct3D/GDI capture, Windows UI Automation).
* **Cognition:** Bidirectional streaming via Gemini 3.8 Live; multi-tier vector memory consolidation; deep reasoning via Gemini 4.
* **Containment:** Secrets sealed via local Windows DPAPI; interactive capability-lease confirmation broker for OS actions; zero telemetry.
* **Stack:** `Rust` · `.NET 10 (C#)` · `TypeScript` · `Three.js` · `Apache-2.0`

```text
[SYS-02] LOCAL-UPI-LEDGER // ANDROID 16/17 PRIVACY AGGREGATOR
```
* **Mission:** Real-time transaction ledger for Samsung One UI 8.5/9 with zero network footprint.
* **Air-Gapped Manifest:** Operates with `0 INTERNET` permissions. Storage persisted in SQLCipher 4.x (AES-256 GCM) with keys anchored in hardware Android Keystore.
* **Kernel Bypass:** Scans in-memory `AccessibilityNodeInfo` hierarchy to extract transaction logs past banking `FLAG_SECURE` screen restrictions without root.
* **Stack:** `Kotlin` · `Jetpack Compose` · `SQLCipher` · `Room` · `AGPL-3.0`

```text
[SYS-03] OPEN-MERCHANT // EXACT-DECIMAL DECISION WORKBENCH
```
* **Mission:** Desktop research workbench evaluating commercial opportunities and unit economics.
* **Deterministic Arithmetic:** Exact-decimal ledger calculations executed purely in verified code (zero floating-point drift, zero LLM hallucinations).
* **AI Gate:** "Draft Desk" human-verification buffer where model suggestions remain inert until approved; includes a bundled read-only stdio MCP server (`open-merchant-mcp`).
* **Stack:** `TypeScript` · `Electron` · `React` · `Zod` · `stdio MCP` · `AGPL-3.0`

```text
[SYS-04] XGHOSTSIGNAL // LOCAL OSINT & RF SIGNAL INTELLIGENCE
```
* **Mission:** Local-first cellular intelligence, RF burst detection, and geospatial entity correlation.
* **Signal Pipeline:** Real-time RTL-SDR spectrum capture, cell-tower geospatial mapping (OpenCelliD/CellMapper), ADS-B flight tracking, and NetworkX relationship graphs.
* **Interface:** Low-overhead terminal CLI (`xgs`) paired with a Cytoscape.js web console with local Ollama summarization.
* **Stack:** `Python 3.9+` · `FastAPI` · `Typer` · `SQLAlchemy` · `PyRtlSdr` · `Scapy` · `MIT`
