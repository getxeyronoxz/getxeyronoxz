### Featured Projects

**[open-merchant](https://github.com/getxeyronoxz/open-merchant)**  
Windows desktop workspace for evidence-based product research and unit-economics analysis.  
Built with Rust (Tauri), React, and TypeScript. Emphasises structured evidence capture, competitor analysis, deterministic calculations, and local project ownership. Designed as a focused research environment rather than a full cloud platform.

**[XGhostSignal](https://github.com/getxeyronoxz/XGhostSignal)**  
OSINT and cellular-intelligence workbench for cell-tower mapping, phone enrichment, RF signal detection, and entity correlation.  
Offers both a CLI (`xgs`) and a web interface. Supports data ingestion from common sources, live RF capture, graph-based correlation, and flexible deployment. Built for authorised research and analysis workflows.
