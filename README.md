### Featured Projects

**[open-merchant](https://github.com/getxeyronoxz/open-merchant)**  
Local-first, AI-native commerce research workbench for evidence-based product decisions, competitor analysis, exact-decimal unit economics, and inspectable opportunity reports.  

Built as a TypeScript monorepo with Electron (Windows, macOS, Linux). Specialist AI assistants draft content that remains clearly marked until approved. All project data and artifacts remain on the user’s machine. Emphasises deterministic calculations, provenance tracking, and local ownership.

**[XGhostSignal](https://github.com/getxeyronoxz/XGhostSignal)**  
Local-first OSINT and cellular-intelligence workbench for cell-tower mapping, phone enrichment, RF signal detection, entity correlation, and related analysis.  

Offers both a CLI (`xgs`) and a web interface. Supports data ingestion from common sources, live RF capture (including RTL-SDR), graph-based correlation, local LLM summarisation, and multiple export formats. Designed for authorised research and analysis workflows; data never leaves the machine.
